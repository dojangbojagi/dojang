Connect a wallet and read its official Dojang record on GIWA Sepolia. See who issued it, when it expires and whether it was revoked.

Placeholder page. The full design for this page is the next step. The header, footer, scenarios and the plan below already follow the master brief.

What this page will do

  • Check the wallet and the network before anything is read.
  • Look up the connected wallet in the official Dojang Verified Address record.
  • Show the issuer, attestation ID, issue date, expiry and revocation when a credential exists.
  • Offer an optional demo issuer for the testnet path, clearly labelled and kept apart from the official credential.
  • Send the visitor to Bojagi only when a usable demo credential exists. Otherwise explain how to get one.

Official and demo stay separate. A demo credential is never shown as official Upbit or GIWA verification. “No credential found” is a valid result, and a network error is never shown as “not verified”.
