## Generation 2 — HyperFrames (current)

Source project: `videos/gyevo-lending-v2-proof/` (a self-contained HyperFrames project; the folder name predates the 28s expansion, kept so the project history/revisions stay attached).

- `index.html` — the full 28s composition. One `<canvas>`-based "glyph sculpture" (a point-cloud of hex characters `0-9A-F`, ported from the site's own `src/components/landing/glyph-solid.tsx` shape math) is the through-line: exposed sphere → sealed core+ring → upright supply ring → two linked rings (supply + borrow), matching the real Lending page's own glyph ("two linked rings: supplying and borrowing, joined by a proof"). A second canvas builds a "health factor" numeral out of the same characters. The reconstructed Eligibility/Markets/Supply/Borrow/Position panels use real copy pulled from `src/components/lending-v2/*.tsx` (see the fidelity notes in the plan file below) — this is a **recreation**, not a screen recording, because the local Lending V2 pool env var is unset so the real app has no live state to capture.
- `archive/proof-5s.index.html` — frozen copy of the 5-second approved opening, in case `index.html` is iterated on later and the original reference is needed.
- `assets/proof-audio.wav`, `assets/film-audio.wav` — rendered audio beds (git-ignored by size/type convention; regenerate from the scripts below if missing).
- `assets/fonts/` — Quicksand 600/700 + JetBrains Mono 400/500, copied from `remotion/public/fonts/` (same family the live site uses).
- `assets/vendor/gsap.min.js` — GSAP vendored locally for deterministic rendering (not loaded from a CDN at render time).
- `scripts/synth-proof-audio.py` / `scripts/synth-film-audio.py` — original synthesized soundtracks (numpy → WAV → the HyperFrames audio pipeline), beat-locked at 120 BPM. The cue grid in each script's docstring must stay in sync with the `T = {...}` object near the top of `index.html`'s `<script>` — they were authored together deliberately; if you retime one, retime the other.
- `AGENTS.md` / `CLAUDE.md` — HyperFrames' own project instructions (how to run `check`, `preview`, `render`; do not hand-edit, they're regenerated by `hyperframes init`/`upgrade`).

### Rebuilding / re-rendering

```bash
cd "videos/gyevo-lending-v2-proof"

# regenerate audio (only if assets/*.wav are missing or you changed a script)
python3 scripts/synth-film-audio.py     # -> assets/film-audio.wav
python3 scripts/synth-proof-audio.py    # -> assets/proof-audio.wav

# validate before rendering
npx hyperframes lint
npx hyperframes check          # will report text_occluded "errors" from the
                                # intentional full-frame glyph canvas layered
                                # over the UI — confirmed harmless by snapshot
                                # inspection, see Known limitations below.

# inspect specific frames without a full render
npx hyperframes snapshot --at 0.1,5.5,14.0,22.0,26.5

# render
npx hyperframes render . --skill=motion-graphics -q high \
  -o "../../out/videos/gyevo-lending-v2-final.mp4"
```

The HyperFrames CLI is invoked via `npx hyperframes` (or `npx --yes hyperframes` non-interactively); the project's `package.json` also pins an exact version in its own `npm run` scripts.

### Creative direction (for anyone extending this film)

- **Color is the message:** white = public / on-chain, ruby `#c41e3a` / burgundy `#6d001a` = private / on-device. Never invert it.
- **One protagonist object:** the glyph sculpture is the through-line across every scene — it is not decoration, it *is* the proof. New scenes should keep moving the same sculpture rather than introducing a second motif.
- **Real copy only:** every panel label, button, chip state, and disclosure string is lifted verbatim from `src/components/lending-v2/*.tsx` and `src/app/lending/page.tsx`. Do not invent UI strings, rates, balances, or tx hashes — see the fidelity table in the planning doc below for the exact source lines used.
- **Disclosures that must stay in any future cut:** "Illustrative · reconstructed UI · Robinhood Testnet" tag during the product scenes; the closing card's "Robinhood Testnet demonstration · Synthetic test assets · Mainnet Lending paused · Not audited · Independent project."
- **Full storyboard, shot-by-shot timing table, and the product-fidelity source table** are in the session's plan file: `~/.claude/plans/pasted-content-id-f039-act-as-goofy-lynx.md` on the machine this was built on. That file is **not** part of this repo (it lives in the agent's local plan directory, outside version control) — copy its relevant sections into this doc or into a repo-tracked file if the storyboard needs to survive a clean clone.

### Known limitations

- `npx hyperframes check` reports `text_occluded` findings because the glyph-sculpture canvas is a full-frame transparent layer intentionally drawn over the UI panels. Frame-by-frame snapshot inspection (both during the build and from the final encoded MP4) confirmed no text is actually hidden in any delivered frame — the checker can't see through a `<canvas>` to know it's mostly empty at a given instant. `lint` is clean (0 errors); render was run on that basis.
- Panel/review text renders at roughly 19–23px at 1080p — legible but small; hierarchy is carried by the giant kinetic type and the health-factor numeral, not the panel copy.
- The health-factor values (2.40 / 1.08 / 0.92, 40% / 92% / 104%) are illustrative, labelled "Illustrative estimate" on screen. Only 100 rUSD2 supplied, 10 rCOL2 collateral, and 3 rUSD2 borrowed match the project's verified testnet history; nothing in the film claims a live wallet signature, a tx hash, or an on-chain confirmation.
- Final audio loudness landed at −15.8 LUFS / −1.6 dBTP (the renderer auto-attenuated 1.5 dB to stay under the −1 dBTP ceiling); target was −14 LUFS. No one has listened to the mix — sync was verified against the shared cue-time grid between the script and the composition, and loudness was verified with `ffmpeg loudnorm`, not by ear.
