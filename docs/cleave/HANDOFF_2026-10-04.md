## 0. Read this first

1. **Re-read a file before editing it.** Commits and parallel edits land continuously (UI, Solidity and deployment scripts are worked on at the same time).
2. **UI and logic are separate territories** (§10). A UI task should not need to touch `lib/adapters/*`, `lib/web3/*`, `lib/contracts/*`, `lib/quotes/*`, `types/*`, `contracts/`, `scripts/`.
3. **User-facing words are "Fixed Yield" and "Trading Yield".** Internally the second strategy is still `long` / YT: `strategy=long`, `kind: "long"`, `useLongYieldQuote`, `openLongPosition`, `hrefs.long`, the `#long` docs anchor. Never rename those to match the copy.
4. **UI must not invent market data.** Numbers and names come from `useMarkets` / `useMarket` / quote hooks; icons through `AssetIcon`. (One known violation is finding F3.)
5. **Visual preferences from the owner** (saved in memory): vivid orange `#EF5F22` and blue `#3B86FF`, never pastel; glass is **dark**, not white; every clickable thing gets `cursor: pointer`.

**Environment** (`.env.local`, template in `.env.example`):

| Variable | Used for |
|---|---|
| `NEXT_PUBLIC_YELTRA_DATA_MODE` | `live` (Pendle on Robinhood mainnet 4663) or `mock` |
| `NEXT_PUBLIC_ROBINHOOD_CHAIN_ENV` | `mainnet` / `testnet` browse network |
| `NEXT_PUBLIC_ROBINHOOD_CHAIN_RPC_URL`, `..._TESTNET_RPC_URL` | public RPCs (they ship to the browser; restrict the keys by domain) |

Modes: the live adapter is mainnet-only (`ENV=testnet` + `live` shows no markets, by design). Mock mode is explicit; it never activates just because a wallet is disconnected.

**Gotchas that cost time before**

- **One `next dev` per project directory.** A second one refuses to start. To check a build on another port: `npx next build --webpack && npx next start -p 3018`.
- **`next dev` caches `tailwind.config.ts`.** After editing colour tokens, restart the dev server; classes like `bg-ice` keep the old colour until you do.
- **Tailwind opacity steps 8 / 12 / 14 / 16 / 18 generate no CSS** (`border-white/12` renders bright `#e5e7eb`). Use 10 / 15 / 20 / 25 / 35. Still present in 12 older files (F5).
- Headless Chrome reports `HeadlessChrome/…` as user agent; `supportsBackdropLens` matches `Chrome/` (no `\b`).
- `Lit is in dev mode` in the console is the wallet library, harmless.
- Zsh: quote globs (`--include='*.tsx'`), or the command silently matches nothing.

## 3. Product vocabulary and flow

| User sees | Meaning | Internal |
|---|---|---|
| **Fixed Yield** | Lock a quoted yield toward maturity; more predictable; early exit is priced by the market | `fixed`, PT |
| **Trading Yield** | Trade exposure to future yield as rates move; value can fall; expires at maturity | `long`, YT |
| Markets | research | `/markets` |
| Trade Yield | execution | `/trade` |

Flow: Landing → `/markets` or `/trade` → `/markets/[id]` ("Trade Yield →") → `/trade/[id]?strategy=` → quote → approve → open → `/portfolio`.
Copy rules: no guarantee language ("quoted", not "locked/guaranteed"), no "leverage/bet", PT/YT only as secondary ("Powered by PT"), wallet never required to browse or preview a quote ("Connect wallet to execute"). The brief-mandated risk sentence stays verbatim in the Review step and trade panel.

## 5. Design system

**Palette** (`tailwind.config.ts`): `ice` `#3B86FF`, `amber` `#EF5F22` (`amber.primary` `#F07A2B` is the Saturn orange used by the logo), `positive` `#8FD3A8`, `negative` `#F08A7A`, `background` `#030304`, `foreground` `#ECEDEA`, `surface` / `muted` ramps. The old pastels (`#A9C8EE`, `#F0A85C`) are gone; canvas, SVG and inline styles hard-code the same values, so grep for `59, 134, 255` / `239, 95, 34` (and bare `59,134,255` in `HeroVisual.tsx`) when you add an accent. `ice.light` / `amber.light` are unused.

**Glass** (`app/globals.css`, `.lg-*`): dark near-clear tint, thin bevel light, rim ring (`::before`), specular arc (`::after`), pointer-follow glow (`.lg-glow`, fed by `--lg-x/--lg-y`), one-time sweep, glass hover bead (`.lg-chip`), solid orange CTA (`.lg-cta`), idle float (`.lg-float`). Used by `FloatingNav` and `ContractAddress`. Refraction (SVG displacement map in `backdrop-filter`) is Chromium-only; other browsers get blur + gloss.

**Buttons.** Global `a:hover { color:#fff }` turns the label of an anchor-styled button white. Coloured CTAs keep their hue on hover (brighter, lifted 1 px, same-colour glow) and carry an explicit `hover:text-[#0A0C10]`; white buttons keep `hover:bg-white` plus `hover:text-background`. Any new anchor button with a dark label needs the explicit hover text class.

**Cursor.** One zero-specificity `:where(...)` rule gives `cursor: pointer` to links, enabled buttons, tabs, `summary`, `select`, `label[for]`, checkbox/radio/range. Utilities like `cursor-not-allowed` still win.

**Shared pieces.** `MarketMetricsStrip` (4-cell strip, market detail + workspace), `AssetIcon` / `ProtocolIcon` (sizes `xs`–`lg`), `DataModeBadge`, `ApplicationBackdrop`, `MarketTable` trade variant (`tradeHrefs`, `defaultSort`).

## 6. Landing specifics

- **Stage copy** is a pure function of market + quotes: `buildStages(featured, fixedQuote, longQuote)` in `heroStages.ts`. `FALLBACK_STAGES` is shown while no market is available (F3).
- **Floating nav** (`FloatingNav.tsx`): appears when the hero section (`id="top"`, pinned runway included) has fully left the viewport (`IntersectionObserver`, fallback `scrollY > innerHeight`); `inert` while hidden; `z-40` (below `SplashScreen` `z-[9999]`). **Do not rename or remove `id="top"`.** The link list is a copy of the one in `Navbar.tsx` (F7).
- **Contract-address pill** (`ContractAddress.tsx`): glass pill at the hero's bottom-left; click copies the address (Clipboard API, `execCommand` fallback) and shows "Copied to clipboard"; the address is `useState(CONTRACT_ADDRESS)`. It steps aside (fade + `inert`) when it would sit closer than 8 px to the hero copy (short or narrow viewports). **It is currently hidden** (F1).
- **X link**: `lib/site-links.ts` → `X_URL = "#"`, used by `Navbar` (landing: always visible; app pages: from `sm` up) and `FloatingNav`; `target="_blank" rel="noopener noreferrer"`.
- **Scroll reveal**: `data-reveal` blocks ease in/out; never put `data-reveal` on an element with its own `transition`.
- **Walkthrough pin** (`TradePreview`): `PIN_QUERY` in the component must match `.trade-runway` / `.trade-pin` in `globals.css`.

## 12. Verification recipes

- **Static checks:** the four commands in §2.
- **Browser checks without a test framework:** headless Chrome with `--remote-debugging-port`, driven through the DevTools protocol (`Page.navigate`, `Emulation.setDeviceMetricsOverride`, `Runtime.evaluate`, `Page.captureScreenshot`, `Input.dispatchMouseEvent` for real hover/click). The splash screen covers the first ~5 s: wait, then click the "Skip" button.
- **Hero stages:** click `#hero-tab-0 … #hero-tab-4` and wait ~3 s for the camera to settle.
- **Hydration:** load the page with a hash (`/docs#transparency`) and watch `Runtime.exceptionThrown` for "Hydration failed" (fixed in `DocsNavigator.tsx`: the active section starts as `"start"` and the hash is applied after hydration).
- **Overlap checks:** measure `getBoundingClientRect()` of the CA pill against the hero copy column at 1280×720, 1366×768, 1440×900, 1024×768, 390×844, 360×640 for all five stages.
- **Colour tokens:** run `next build && next start -p <port>` rather than trusting a long-running dev server.
